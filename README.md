# わり算ラボ（拡張版）

小学生向けの「わり算」学習Webアプリです。1つの `index.html` だけで動きます（ビルド不要・ブラウザで開くだけ）。

## あそびかた

`index.html` をブラウザで開いて、ラボ（モード）をえらびます。各問題は3ステップ:

1. **分けて体験**（たば＆ばら／ビーカーで「わり算」を実感）
2. **筆算**（数字をえらんで進める）
3. **たしかめ算**（かけ算で元にもどす）

### モード（やさしい順）

- ➗ **2ケタ ÷ 1ケタ ラボ**（整数・いちばん基本）… 10のたば＆ばらで位取りから理解
- 🧪 小数 ÷ 整数 ラボ
- 📏 整数 ÷ 小数 ラボ
- 🥤 小数 ÷ 小数 ラボ

各モードに **🌱 れんしゅう（タイマー無し）** と **🔥 ちょうせん（タイマーあり）** があります。

### おうちのひと へ（親モード）

ホーム下の「⚙️ おうちのひと へ」から:

- **問題数の設定**（3〜20問）
- **📒 まちがいノート**（まちがえた・時間切れの問題を記録、一覧・消去）
