# わり算ラボ（拡張版）

小学生向けの「わり算」学習Webアプリです。**1つの `index.html` だけ**で動きます（ビルド不要・依存なし・ブラウザで開くだけ）。

🎮 **あそべるページ:** https://narupeko.github.io/warizan-lab-ex/

わり算の意味（分ける体験）から、九九でとくわり算、そして筆算までを、**やさしい順の「学習の階段」**として一気通貫で練習できます。

---

## あそびかた

`index.html` をブラウザで開く（またはライブページにアクセス）→ ラボ（モード）をえらぶだけ。

各問題はモードに応じて最大3ステップで進みます：

1. **① 分けて体験** … 具体物で「わり算」を実感（モードにより たば＆ばら／長方形／ビーカー）
2. **② 計算** … 九九でとく、または筆算（数字をえらんで進める）
3. **③ たしかめ算** … かけ算で元の数にもどるか確認

「分け方」や「①〜③のどれを使うか」はモードごとに最適化しています（下表）。

---

## モード（やさしい順）

ホームの上から順に、やさしい→むずかしい に並んでいます。

| モード | 内容 | ① 分ける | ② 計算 | ③ たしかめ |
|---|---|---|---|---|
| 🟢 **わり算きほん** | 九九でとく 1桁の答え（〜81、あまりあり）。筆算なしの入口 | 長方形（九九）で分ける | 「◯ × ? ＝ ◯」を九九でえらぶ | — |
| ✏️ **九九のわり算 ひっ算** | 商が1けたの筆算。`56 ÷ 7` のような「商の十の位が立たない」形に対応 | （省略） | 筆算（たてる→かける→ひく→あまり） | あり |
| ➗ **2ケタ ÷ 1ケタ ラボ** | はじめての本格筆算。位取りから理解 | 10のたば＆ばらで分ける | 数字えらびの筆算（下に計算過程・あまりまで表示） | あり |
| 🧪 **小数 ÷ 整数 ラボ** | 小数を整数で分ける | ビーカーで分ける | 筆算 | あり |
| 📏 **整数 ÷ 小数 ラボ** | 「何コ分とれる？」を体験 | ビーカー（コップ） | 両方を10倍して整数のわり算 | あり |
| 🥤 **小数 ÷ 小数 ラボ** | 小数を小数で分ける | ビーカー（コップ） | 両方を10倍して整数のわり算 | あり |

### ✏️「九九のわり算 ひっ算」のポイント

`56 ÷ 7` のような問題では、「**5 は 7 で われないので、56 で かんがえる**」と案内し、商の十の位を空けて一の位に「8」を立てます。これは「2ケタ÷1ケタ」の手前の、つまずきやすい大事なステップです。

### れんしゅう / ちょうせん

**➗ 2ケタ ÷ 1ケタ ラボ** だけ、ボタンを押すと2つから選べます：

- 🌱 **れんしゅう** … タイマー無しで、筆算をゆっくり
- 🔥 **ちょうせん** … タイマーあり

その他のモードはタイマーありの1ボタンです。

---

## ⚙️ おうちのひと へ（親モード）

ホーム下の「⚙️ おうちのひと へ」から設定・記録を見られます：

- **問題数の設定**（3〜20問・全モード共通／設定は保存されます）
- **📒 まちがいノート** … まちがえた・時間切れになった問題を新しい順に記録（式・答え・回数・日付）。一覧表示と全消去ができます

---

## そのほかの仕組み

- **タイマー＆バクハツ💥** … 時間切れになると演出が出て、**同じ問題からやり直し**
- **🔥 コンボ** … ノーミスで連続正解するとコンボが伸びる
- **ベストタイム** … モードごとに最速タイムを記録（8割以上正解で更新）
- **🏠 ホームボタン** … ゲーム中いつでもホームへ戻れる
- データは端末内（`localStorage`）に保存。サーバー送信はありません

---

## 技術メモ

- 単一ファイル（`index.html`）／プレーン HTML・CSS・JavaScript／ビルド・依存なし
- 保存キー: `warizan_qcount`（問題数）, `warizan_mistakes`（まちがいノート）, `warizanlab2_<mode>`（ベストタイム）
- フォントは Google Fonts を読み込みます（見た目用。ロジックはオフラインでも動作）
- 公開は GitHub Pages（このリポジトリの `master` ルートを配信）
